# online-tools

Free, single-file web tools for French independent professionals. No account, no tracking, no data leaves the browser.

| Tool | Live | For |
|---|---|---|
| Mon soutien psy simulator | https://aflouat.github.io/online-tools/psy-simulateur/ | Self-employed psychologists |

Each tool lives in its own folder as a standalone `index.html` (no build step, no dependencies).

Suggest a tool or report a wrong figure: open an issue.
